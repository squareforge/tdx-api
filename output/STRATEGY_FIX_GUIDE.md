# 策略权重修正 - 实施指南

## 📊 问题发现

通过双轨回测分析，发现了**致命问题**：

```
排名算法完全反向！
- Top3优于其他：0/5天 = 0% 
- Top3成功率：33.3% < 整体42.3%
- Top3平均收益：-1.82% < 其他-1.57%
```

**根本原因**：因子权重与相关性相反！

---

## 🔬 相关性分析

| 因子 | 相关系数 | 解读 | 当前权重 | 问题 |
|------|---------|------|---------|------|
| TREND | **-0.367** | 强负相关 | 25分(高) | ❌ 涨幅越大反而越危险 |
| RISK | **+0.361** | 强正相关 | 10分(低) | ❌ 稳定性高反而低分 |
| VOLUME | +0.150 | 中正相关 | 20分 | ✅ 合理 |
| STRENGTH | -0.112 | 中负相关 | 15分 | ⚠️ 应降低 |
| PULLBACK | +0.046 | 弱相关 | 20分 | ~ 影响不大 |
| LIQUIDITY | -0.018 | 弱相关 | 10分 | ~ 影响不大 |

### 关键发现

**TREND负相关-0.367**：
```
高TREND分 = 涨幅大(45%+) → 已在高位 → 容易回调 → 收益差
案例：中京电子 20日涨55%, rank=70.6 → 最终-18.8%
```

**RISK正相关+0.361**：
```
高RISK分 = 振幅小(稳定) → 相对安全 → 持续性强 → 收益好
案例：顺络电子 20日涨38%(适中), rank=68.5 → 最终+21.1%
```

## 🔧 权重调整方案

### 对比表

| 因子 | 旧权重 | 新权重 | 变化 | 原因 |
|------|--------|--------|------|------|
| **RISK** (max_amplitude) | 10分 | **25分** | ⭐ +15 | 正相关+0.361，最重要 |
| **VOLUME** (volume_up) | 20分 | **20分** | = | 正相关+0.150，保持 |
| **TREND** (gain_days) | 25分 | **15分** | ⚠️ -10 | 负相关-0.367，降低 |
| **PULLBACK** (drawdown) | 20分 | **15分** | -5 | 弱相关，略降 |
| **LIQUIDITY** (min_amount) | 10分 | **15分** | +5 | 补充基础分 |
| **STRENGTH** (close_strength) | 15分 | **10分** | -5 | 负相关-0.112，降低 |
| **总分** | 100分 | 100分 | - | - |

### 核心逻辑改变

**修正前**：
```
rank_score = TREND×25 + PULLBACK×20 + VOLUME×20 + STRENGTH×15 + ...
           = 追高×高权重 → 选出涨幅大的股票 → Top3更容易失败
```

**修正后**：
```
rank_score = RISK×25 + VOLUME×20 + TREND×15(区间) + ...
           = 稳定性×高权重 → 选出持续性强的股票 → Top3应该更优
```

### TREND区间评分（新增）

**旧逻辑**：涨幅越高分越高
```
20日涨55% → 10/10分 ← 实际很危险！
20日涨30% → 6/10分
```

**新逻辑**：25-35%为最优区间
```
20日涨55% → 5/10分 ← 过高，扣分
20日涨30% → 10/10分 ← 甜蜜点，满分
20日涨15% → 6/10分 ← 略弱
```
