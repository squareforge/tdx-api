## 🎯 整体策略评价

### 策略定位
从代码和信号数据分析，这是一个**趋势回踩+放量突破**策略：
- 选择强势上涨股（MA多头排列，20日涨幅45%+）
- 等待小幅回调（距高点回撤5-10%）
- 放量重新启动时买入

### 策略类型
**动量策略** (Momentum Strategy)

### 理论基础
✅ 符合市场规律：
- 趋势延续性
- 强者恒强
- 放量突破有效

### 实际问题
🔴 当前执行结果不佳的原因：

#### 1. 市场环境问题 ⚠️
从6月5日-6月11日，如果大盘处于调整期，动量策略会失效。

**建议增加市场状态过滤**：
```json
{
  "filters": [
    {
      "factor": "market_momentum",
      "params": {
        "days": 20,
        "min": -5,   // 上证指数20日跌幅不超过5%
        "max": 100
      }
    }
  ]
}
```

#### 2. 买点过早 ⚠️
53.8%的信号次日开盘低于买入区间，说明：
- 信号日收盘价偏高
- 次日低开幅度被低估

**当前买入价格区间**（从signals数据推测）：
```

buy_price_high = signal_close * 1.02  // 允许2%溢价
```

**问题**: 这个区间假设次日平开或高开2%以内，但实际：
- 26.9%次日低开
- 53.8%开盘价低于这个区间

**优化建议**：
```python

buy_price_high = signal_close * 1.015 # 高开1.5%以内可追
```

#### 3. 前期涨幅过大 🔴
**这是核心问题！**

```python
import scipy.stats as stats
# 盈利率 42.3%，样本量26
# H0: 真实盈利率 = 50% (随机)
# H1: 真实盈利率 < 50%

z = (0.423 - 0.5) / (0.5 * 0.5 / 26) ** 0.5
# z ≈ -0.78, p-value ≈ 0.22

# 结论: p > 0.05，不能拒绝H0
# 即：无法证明策略比随机好或差
```
