## 💡 核心要点

### 问题本质

```
不是持仓限制的问题（影响仅-0.22%）
而是排名算法反向的问题（Top3从未跑赢）
```

### 根本原因

```
TREND因子：负相关-0.367，但给了高权重25分
RISK因子：正相关+0.361，但只给了低权重10分

→ 排名越高 = TREND分越高 = 涨幅越大 = 越危险
→ Top3反而表现更差
```

### 修正方案

```
RISK:  10分 → 25分 ⭐ 提到最高权重
TREND: 25分 → 15分 ⚠️ 大幅降低
+ TREND改为区间评分（25-35%最优）
+ 增加涨幅上限45%
+ 增加市场状态过滤
```

### 预期效果

```
Top3优于其他: 0% → >60%
Top3成功率:   33.3% → >50%
排名有效性:   反向 → 正向
```

## 🎓 经验教训

1. **双轨评估很重要**
   - 无限制买入 → 评估策略整体质量
   - 有限制买入 → 评估排名算法有效性
   - 两者结合才能全面诊断

2. **相关性分析是金矿**
   - 发现TREND负相关（违反直觉）
   - 发现RISK正相关（振幅小更好）
   - 数据比直觉更可靠

3. **不要被直觉误导**
   - 直觉：涨幅大 = 强势 = 应该买
   - 数据：涨幅大 = 透支 = 容易回调
   - 量化就是要战胜认知偏差

4. **排名和选股同样重要**
   - 策略整体42.3%（一般）
   - 但排名反向让Top3只有33.3%（更差）
   - 修正排名可能比优化因子更有效
