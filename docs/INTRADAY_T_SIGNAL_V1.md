# 日内做T信号方案 V1（讨论稿）

> 本文档是方案讨论文档，不等同于代码实现，也不等于投资建议。
> 定位：在已有 TDX 实时快照推送和底仓的前提下，只输出「买入/卖出信号」供人工执行，不接自动下单。

---

## 1. 背景与目标

- 已有 TDX 实时快照订阅（项目内 `QuoteHub` 每 3 秒轮询 `GetQuote` 并推送给订阅者，也可替换为真正的服务端推送接口）。
- 已持有某只股票底仓，做日内 T 以摊低成本。
- 系统职责边界：**只负责出信号，不负责下单、不负责仓位、不负责隔夜规划**。执行权在人。
- A 股 T+1 前提：当天卖出的是昨日及更早买入的筹码；当天买入的部分当天不可卖出，但底仓始终可卖。

### 1.1 已确认配置（2026-09-18）

| 项 | 确认值 |
| --- | --- |
| 做T标的 | 单只固定标的 |
| 信号粒度 | 1分钟触发（方向过滤用 5分钟确认，回测验证无效可去掉） |
| 信号推送 | Webhook（项目已有 webhook 能力） |
| 单笔仓位 | 底仓的 1/3 |

## 2. 数据基础：快照 → 分钟K合成

### 2.1 快照可用字段（`protocol.Quote`）

| 字段 | 含义 | 用途 |
| --- | --- | --- |
| `Kline.Close` | 最新价（当日快照K线） | 分钟bar的 open/high/low/close 来源 |
| `Kline.Volume` | 当日累计成交量（手） | 分钟bar成交量 = 累计量差值 |
| `Kline.Amount` | 当日累计成交额（元） | 分钟bar成交额 = 累计额差值 |
| `ServerTime` | 服务器时间戳 | 分钟归属判定 |
| `Intuition` | 现量（最近成交单量） | 急拉急跌信号辅助 |
| `Rate` | 涨速（百分比） | 急拉急跌信号辅助 |
| `BuyLevel/SellLevel` | 五档盘口 | 可选的盘口确认 |

单位约定（沿用项目 `MEMORY.md`）：`Price` 为毫元（÷1000 显示），`Volume` 为手（×100 转股）。日内合成不做复权。

### 2.2 分钟bar合成公式

每分钟收盘（或任一快照到达时更新当前bar）：

```text
bar.time   = 分钟起点（如 10:35:00）
bar.open   = 该分钟内第一条快照 close
bar.high   = max(该分钟内全部快照 close)
bar.low    = min(该分钟内全部快照 close)
bar.close  = 该分钟内最后一条快照 close
bar.volume = 分钟结束时累计Volume - 分钟开始时累计Volume
bar.amount = 分钟结束时累计Amount - 分钟开始时累计Amount
```

第一条快照到达时初始化当日累计基准（开盘前累计量为 0 或异常值时丢弃，取第一个合法值）。

### 2.3 边界与切分规则（必须处理，否则信号会错）

- **开盘集合竞价（9:15–9:25）**：以 9:25 撮合价初始化第一根 9:30 bar 的 open。
- **午休（11:30–13:00）**：11:30–13:00 必须切bar，禁止把上午尾和下午头合并。
- **分钟边界**：按 `ServerTime` 归属分钟，跨分钟重开bar。
- **收盘**：深市 14:57–15:00 收盘竞价、沪市 15:00 收盘；最后一根 bar 的 close 必须等于当日收盘价（以最后快照为准）。
- **断流/停牌**：快照 gap 超过阈值（如 > 30 秒）时标记该区段为不完整，不得把跨 gap 的高低点合入同一根 bar；连续无快照视为停牌，不产生信号。
- **累计量重置/异常**：累计量回退（如数据源切换）时重置基准，该分钟bar标记为不可信。

### 2.4 精度说明

- 快照默认 3 秒一次，1 分钟内约 20 个采样点。
- 分钟 bar 的 close 基本准确，high/low 会低估真实极值（两个采样点之间的极值会漏掉）。
- **分钟级信号（1min/5min）完全够用；秒级触发价信号不可靠**。信号触发价必须留余量（如 ±0.1%），不按快照精确价设计。

## 3. 做T模式决策：默认「先卖后买 + 趋势否决」

### 3.1 模式对比（底仓在手，两种都合法）

| 维度 | 先卖后买（高抛低吸） | 先买后卖 |
| --- | --- | --- |
| 机制 | 高位卖底仓 → 跌回买回 | 低位加仓 → 高位卖老仓 |
| 最坏情况 | 卖飞：卖完继续涨，买回价更高，该笔小亏 | 买完下跌：新买部分 T+1 卖不掉，被迫隔夜加仓 |
| 风险结构 | 永不被动增加隔夜持仓 | 判断错时被动隔夜扛单 |
| 适配行情 | 震荡 / 均值回归 | 单边上涨 |
| 对信号的容错 | 高，适合人工执行 | 低，需严格纪律 |
| 推荐度 | **默认** | 不推荐起步 |

### 3.2 结论

- 默认模式：**先卖后买**，信号锚定均值回归（VWAP、均线、背离）。
- 必须配「趋势否决」开关，避免无脑高抛低吸在单边日反复打脸。

### 3.3 趋势否决规则（每日开盘后持续判定）

| 状态 | 判定条件 | 信号行为 |
| --- | --- | --- |
| 强势单边 | 价 > VWAP 且偏离 > 1% 且量比 > 1.5 | 不发卖出信号，只观望；激进者可切换先买后卖（不推荐起步） |
| 弱势单边 | 价 < VWAP 且放量下杀（量比 > 1.5） | 只提示减仓/离场，不提示买回 |
| 震荡 | 价格围绕 VWAP 波动、量能温和 | 正常发「高抛 → 低吸」信号 |
| 涨跌停附近 | 距涨停 < 1% 或距跌停 < 1% | 不操作 |

## 4. 信号体系

信号粒度：**1分钟触发 + 5分钟方向确认**。1分钟负责灵敏触发，5分钟负责过滤假信号；若回测显示 5分钟确认无增益，则退化为纯 1分钟。

### 4.1 一条信号的最小结构

```text
方向       : SELL_FIRST（高抛） / BUY_BACK（低吸买回） / REDUCE（减仓） / STAND_ASIDE（观望）
触发条件   : 具体可计算的规则（见 4.2）
建议价位   : 触发价 ± 余量
目标价     : 必须给（不成对不发）
止损价     : 必须给（不成对不发）
有效期     : 例如「10:00–14:00 内有效，过期作废」
仓位建议   : 底仓的 1/3
```

没有目标价和止损价的信号视为噪音，系统不得发出。

### 4.2 候选信号规则（初始参数，需回测校准）

| 编号 | 信号 | 触发条件（初值） | 出场/止损 | 说明 |
| --- | --- | --- | --- | --- |
| S1 | VWAP 回归 | 1min收盘偏离 VWAP 超 ±0.5% 且回归动能出现（3min内价回到偏离 0.2% 以内） | 目标：回到 VWAP；止损：偏离扩大至 0.8% | 震荡市做T主锚 |
| S2 | 分时均线支撑/压力 | 1min价回踩 VWAP/均线不破（收盘价未跌破均线） | 目标：前高/前低；止损：跌破/突破均线 0.3% | 配合 S1 使用 |
| S3 | 1min MACD 背离 | 价创新高/新低，MACD(12,26,9) 不创新高/新低 | 目标：背离后回到前高/前低；止损：背离失效（价继续创新高/新低） | 过滤单边趋势，只在背离成立时提示 |
| S4 | 早盘放量突破（可选） | 9:45 后突破开盘15分钟高点且量比 > 1.5 | 目标：+0.8%；止损：回踩突破价 | 追涨类，频率低、止损要硬 |
| S5 | 急拉急跌反转 | 30秒–1分钟内涨/跌幅超 1.5% 且现量（Intuition）放大、出现滞涨/止跌 | 目标：急拉/急跌起点；止损：继续同向 0.5% | 快进快出，信号频率必须压住 |

### 4.3 全局过滤（每条信号都必须先过 Filter）

- **时间窗口**：只在 10:00–11:00 与 13:30–14:30 发新信号；9:30–9:45 乱动期、14:30 后不发新信号。
- **成本门槛**：该笔往返预期收益（目标价 − 触发价 − 双程佣金 − 印花税 − 滑点）< 0.3% 时不发。参考费率：卖出印花税 0.05% + 佣金双边。
- **数据质量**：当前分钟bar不完整 / 停牌 / 断流时不发。
- **当日已执行对冲**：同一股票同一方向的已有信号未了结前，不重复发同向信号。

### 4.4 信号生命周期

```text
NEW（刚触发） → ACTIVE（有效期内等待执行） → EXECUTED（已按信号成交，人工标记）
                                          → CANCELLED（过期 / 趋势否决 / 人工撤销）
```

每个 SELL_FIRST 信号都必须绑定一个后续 BUY_BACK 条件；当日无法触发买回条件时，收盘前提示「放弃回补 / 隔日处理」。

### 4.5 信号输出示例（JSON）

```json
{
  "id": "T-20260918-000001-S1-01",
  "symbol": "sz000001",
  "time": "2026-09-18T10:35:00+08:00",

  "rule": "S1_VWAP_REGRESSION",
  "trigger": "5min收盘价偏离VWAP 0.62%，3min内回归至0.2%以内",
  "price_zone": { "ref": 11.32, "tolerance": 0.01 },
  "target": 11.12,
  "stop": 11.42,
  "expire_at": "2026-09-18T14:00:00+08:00",

  "follow_up": { "rule": "BUY_BACK_AT_VWAP", "ref": 11.12 }
}
```

## 5. 执行纪律（信号系统外的硬约束）

1. **单次只用底仓的 1/3 做T**，全仓进出会导致卖飞后无弹性和错过最佳回补点。
2. **买卖成对**：不允许出现只提示卖出、不提示何时买回的裸信号。
3. **止损无条件执行**：信号自带止损，触达即按计划，不临时改。
4. **当日封盘**：14:30 后不发新信号；持有中的信号必须在收盘前给出结论（买回 / 放弃回补）。
5. **连续亏损暂停**：单日做T亏损达到底仓的 1% 或连亏 3 笔，当日停止出信号（冷却）。
6. **不预测隔夜**：策略只在日内完成闭环，不因当天没走完而隔夜加仓。

## 8. 风险与免责

- 快照合成分钟K存在 high/low 低估的固有误差，秒级触发价不可依赖。
- 信号基于技术指标，不保证盈利；单边行情、消息面冲击会导致信号失效。
